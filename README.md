## 开始游戏

解压发行包，进入 baiyi-zhiguailu 目录，运行：

```sh
python3 -m http.server 8765
```

用浏览器打开 http://localhost:8765 。无需安装前端依赖，也不需要任何AI服务密钥。详细开发说明与微信配置方法见压缩包中的README.md。

## 当前内容

- 新章节和相关人物支线按故事时序编排。
- 每5次有效行动为1个游戏日，首次看完视频也推进1日。
- 连续5个游戏日未完成科研会触发死亡结局。
- 保留临床工作、休息、知识考核、金币、随机事件、纪念馆与自由换装。
