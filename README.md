# 白衣志怪录

一款以年轻医生李晨光为主角的医院生存叙事游戏。玩家在工作、科研、休息和学习之间安排时间，观看完整剧情，并在片尾决定人物的下一步。

当前版本包含32章主线、9段人物支线和41段完整横屏视频。浏览器版可以离线运行，工程同时保留微信小游戏入口与可选的云排行榜后端。

## 开始游戏

下载或克隆仓库后，在项目目录运行：

```bash
python3 -m http.server 8765
```

用浏览器打开 `http://localhost:8765`。仓库已包含 `index.html`、`browser.js`、图片和全部视频，无需安装前端依赖，也不需要密钥。

横屏体验更适合观看剧情。首次完整看完视频会推进游戏时间；暂停时会保留播放位置。

## 玩法

- 主控为李晨光。开场选择医生、医学生或其他职业，用于本机调查设置，不改变角色能力。
- 5次有效行动为1个游戏日，主线或支线首次看完也推进1日；重看不重复计时。
- 连续5个游戏日没有完成科研，会直接进入死亡结局。科研后重新计时，准备标书不等于完成科研。
- 连续7日未参与临床会使本局存活计时归零；日历和金币继续保留。
- 每28日进行知识考核，可以消耗金币查阅提示；已经回答的题目不重复出题。
- 初始50金币，临床工作有即时收入和月度工资，娱乐需要金币，不设充值。
- 随机事件、持续状态和不同结局共同影响旅程。每次死亡单独进入纪念馆，读档恢复50血量并恢复节点记录的科研期限。
- 穿搭可以随时更换；完成全部主线后解锁女版形象，已经获得的资格会保留。

人物故事可从“人物档案”进入。主线按人生阶段排列，游戏章序与原作编号分别显示。当前原作第32章没有对应视频，因此没有加入占位章节。

## 开发与验证

开发时使用 Node.js 24 和 Python 3.12。浏览器构建与测试不需要安装npm依赖。

```bash
npm run build
npm run build:cloud
npm test
npm run test:cloud
npm run check:privacy
```

`npm run build`只更新浏览器脚本和页面。需要把所有视频嵌入单个HTML时，运行：

```bash
npm run build:standalone
```

单文件版本较大，生成后不会进入Git记录。视频压缩工具需要FFmpeg；可选的无损WebP内嵌优化需要Pillow。普通运行不需要这些工具。

## 目录

| 目录 | 内容 |
| --- | --- |
| `src/` | 规则、界面、存档、纪念馆、形象与问卷模块 |
| `data/` | 章节、支线、人物、知识题和安全默认配置 |
| `assets/` | 场景、角色、穿搭与视频封面 |
| `media/` | 32段主线和9段支线视频 |
| `tests/` | 游戏规则、播放流程与兼容性测试 |
| `tools/` | 构建、媒体处理、包体和公开内容检查 |
| `cloudfunctions/` | 可选微信云排行榜与服务端验证 |

## 微信小游戏

用微信开发者工具导入项目。工程保留测试AppID，正式使用时需配置自己的AppID、HTTPS视频域名及合法媒体域名。视频文件不放入微信代码包，需要从配置的媒体地址加载。

云排行榜默认关闭；本机榜单可以直接使用。正式部署时再按[云排行榜接入说明](docs/leaderboard-setup.md)配置自己的云环境。开发者本机配置文件、环境文件和凭据均应留在仓库外。

目前已通过自动化规则测试和界面流程检查，尚未完成微信真机验证或应用审核。

## 数据与隐私

默认游戏把进度、纪念馆、形象和答题历史保存在当前设备。仓库不包含真实玩家存档、研究答卷或患者数据，也不包含私人素材库链接和本地工作路径。

职业倦怠问卷模块默认关闭，题目为空。若开展正式研究，需要自行配置获准使用的题本和研究流程。启用云排行榜时，需要另行说明上传内容并配置自己的服务。

剧情为文学创作，知识卡用于学习，不能替代真实临床诊疗。

代码和视听素材未附加开源许可证；仓库可见性不代表额外授予素材再分发许可。
